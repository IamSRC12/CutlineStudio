## Overview

Smart multi-track audio trimmer, waveform editor, lyric aligner and sample-accurate DAW production suite.

## ✨ Features

- Multi-track timeline with trim, slice and sample-accurate editing
- Waveform editing and studio-grade audio preview
- Lyric alignment with ASR (Whisper) and Needleman–Wunsch matching
- Production suite for building and exporting complete tracks

## 🚀 Getting Started

```bash
$ npm install
$ npm run dev      # or: npm start
# Windows: double-click START.bat for a one-click launch
```
